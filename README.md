# simple-todo
A simple miniature todo made with Python and PyQt6 library.

# Installation
Go to [releases](https://github.com/jjoltt/simple-todo/releases) to download the latest prebuilt release.
## Want to build it yourself?
Clone this repository and run `makepkg -si` to build it.

# Usage
Run `simple-todo` in terminal or use your Desktop Environment's launcher app to launch the app via its `.desktop` file.
